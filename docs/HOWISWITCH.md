# #HowISwitch post (draft)

I gave an AI agent a seat in a hospital workflow and then took away its keys.

With @switch, a patient's bedside channel, the nurse station and the doctor's room are separate rooms. No agent is in the patient's. The agent that answers the doctor must cite chart entries, and a small service checks every citation. Make one up and it's flagged in the thread.

Only a doctor's verified decision changes the record. Fictional data, built in 4 days.
